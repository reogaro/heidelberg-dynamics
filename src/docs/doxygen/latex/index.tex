Minimal overhead added to create unit tests. Declare a unit test function by adding a {\ttfamily \mbox{[}CSTest\+Function\mbox{]}} onto a static, parameterless function with a {\ttfamily Result} return type. After that, you can load and run your tests effortlessly.\hypertarget{index_autotoc_md6}{}\doxysection{\texorpdfstring{How to Use}{How to Use}}\label{index_autotoc_md6}

\begin{DoxyEnumerate}
\item Press the build button before enabling the plugin. This is to allow the plugin to build the necessary files to run.
\item Ensure the plugin is enabled in the Godot editor.
\item In a script, write a test function. Test functions must be static, parameterless, be prepended with the {\ttfamily \mbox{[}CSTest\+Function\mbox{]}} attribute, and return a {\ttfamily Result} type, indicating it\textquotesingle{}s success or failure.
\begin{DoxyItemize}
\item If an exception is thrown in your function, it will be counted as a fail.
\end{DoxyItemize}
\item Open the "{}\+C\# Testing"{} ui on the editor (it should be on the right by default).
\item Click "{}\+Load Tests"{}. This should populate the dock with a list of all your test functions and the types that they reside in.
\item Click on "{}\+Run Tests"{} to run each of the tests.
\end{DoxyEnumerate}\hypertarget{index_autotoc_md7}{}\doxysection{\texorpdfstring{Example Test Functions}{Example Test Functions}}\label{index_autotoc_md7}
